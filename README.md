# TaskForge

This is a Python project I made while learning Python.

## What it does

TaskForge is a desktop task manager that lets users add, delete, and complete tasks through a graphical interface.

## Features

- Add tasks
- Delete tasks
- Mark tasks as completed
- View completed tasks in a separate list
- Track completed tasks with a counter
- Scroll through task lists
- Handle long task descriptions using text wrapping
- Update the interface dynamically

## What I learned

- Using CustomTkinter to build a GUI
- Creating frames, labels, entries, and buttons
- Using lists to store tasks
- Creating functions and button callbacks
- Using lambda functions
- Refreshing widgets dynamically
- Using `wraplength` to handle long text
- Keeping the interface updated when data changes

## How to run

1. Install Python.
2. Install CustomTkinter using `pip install customtkinter`.
3. Run `TaskForge.py`.
